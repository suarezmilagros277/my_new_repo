# my_new_repo

Este proyecto analiza datos de vehículos usados en Estados Unidos.

## Estructura del proyecto

- `app.py`: Script principal del proyecto.
- `vehicles_us.csv`: Conjunto de datos de vehículos usados.
- `notebooks/EDA.ipynb`: Notebook para el análisis exploratorio de datos.
- `requirements.txt`: Lista de dependencias necesarias.

## Instalación

Instala las dependencias con:

```sh
pip install -r requirements.txt
```

## Uso

Ejecuta el script principal:

```sh
streamlit run app.py
```
